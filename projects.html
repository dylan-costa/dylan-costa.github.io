Web App · Cryptography

Secure Messenger

Try it live View on GitHub

This is the final deployment of the Secure Messenger app, an end-to-end encrypted messaging web app I built during my Spring 2026 independent study in applied cryptography and encryption methods.

Messages are encrypted client-side, in the browser, before they ever reach the server, so the server only ever handles ciphertext — never plaintext messages or the keys needed to read them. The app has a Python backend and a JavaScript frontend, with a dedicated cryptography test suite (Vitest) plus backend and end-to-end tests (pytest, Cypress) that run automatically in CI before every deploy. The frontend is deployed on Vercel and the backend on Render.

To try it, sign up for a free account on the live site above and send yourself (or a friend) a message.

Data Pipeline · Forecasting

WNBA Analytics

View live forecast View on GitHub

A WNBA game-prediction pipeline and forecasting site. It pulls every game since the league's first season (1997) from the official stats API, rates every team with an Elo system adapted from FiveThirtyEight's NBA methodology, and uses those ratings to predict upcoming games and run 20,000-simulation Monte Carlo forecasts of the rest of the season and the playoffs.

The live site shows each team's title odds, semifinal and finals odds, and a full playoff-bracket table, alongside how well the model is actually doing: percentage of correct picks, log loss, and a live record of picks made before tip-off. Everything regenerates automatically every morning as new games come in. The full methodology — the Elo formula, the simulation design, and backtested accuracy on held-out seasons (2019–2026, never used for tuning) — is written up with proofs in the repository.
